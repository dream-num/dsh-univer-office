# DSH × Univer Plugin — Installation Guide

This plugin lets DeepSeek Harness create, edit, inspect, export, preview, and review Univer files. When the AI uses a `univer_*` tool, a **preview card appears right in the conversation** — click it to view the file fullscreen inside the app, no browser needed.

## Install (three steps)

1. **Double-click this zip** — macOS unzips it into a folder (e.g. `univer-dsh-plugin`)
2. Open the folder, **double-click `install.command`** — a terminal window opens and installs automatically; it ends with 「🎉 Installation complete」— press any key to close
3. Open **DeepSeek Harness** and press **Cmd + R** to refresh

> If double-clicking does nothing (macOS security): right-click `install.command` → **Open** → **Open** again.

## How to use

1. Ask the AI to use the `univer_*` tools in a session (e.g. "use Univer to create a sales spreadsheet")
2. When the turn finishes, a preview card appears automatically:

```
┌────────────────────────────────────────┐
│ 📊 销售表格.univer  [wt-xxx]  [展开预览 ▾] │
│ /Users/.../销售表格.univer              │
└────────────────────────────────────────┘
```

3. **Click the card** → view fullscreen in-app; close with ✕, clicking outside, or Esc
4. Multiple sessions work in parallel — each shows its own cards

## Troubleshooting

| Situation | What to do |
| --- | --- |
| No global univer CLI | Nothing else is required; creation, editing, inspection, export, preview, and Worktree review are bundled. |
| No card after install | Make sure you refreshed (Cmd+R); cards appear only **after** a turn uses a structured `univer_*` tool. |
| Card shows a **yellow dot** | The bundled Gateway is not running; click the dot to start it |
| Want to uninstall | Delete `~/.dsh/profiles/node_modules/dsh-univer-office` and remove the matching lines from `~/.dsh/profiles/web/cordis.patch.yml` |

## Requirements

- Apple Silicon macOS + DeepSeek Harness installed (required by the current prebuilt zip)
- No terminal skills or Node needed — just double-click
