# DSH × Univer 插件 — 安装说明

这个插件让 DeepSeek Harness 可以创建、编辑、检查、导出、预览和审阅 Univer 文件。AI 使用 `univer_*` 工具后，**预览卡片直接出现在对话里**，点一下就能在应用内全屏查看，不用开浏览器。

## 安装（三步）

1. **双击这个 zip**，Mac 会自动解压成一个文件夹（名字类似 univer-dsh-plugin）
2. 打开文件夹，**双击「install.command」**，会弹出一个终端窗口自动安装，最后显示「🎉 安装完成」——按任意键关闭窗口
3. 打开 **DeepSeek Harness**，在窗口里按 **Cmd + R**（刷新）

> 如果双击没反应（Mac 安全限制）：右键点「install.command」→ 选「打开」→ 再点「打开」即可。

## 怎么用

1. 在会话里让 AI 使用 `univer_*` 工具（比如“用 Univer 生成一个销售表格”）
2. 这个回合结束后，对话里自动出现一张预览卡片：

```
┌────────────────────────────────────────┐
│ 📊 销售表格.univer  [wt-xxx]  [展开预览 ▾] │
│ /Users/.../销售表格.univer              │
└────────────────────────────────────────┘
```

3. **点卡片** → 应用内全屏看表格；点 ✕、点外面遮罩、或按 Esc 关闭
4. 同时开多个会话也没事 —— 各会话显示各自的卡片

## 常见问题

| 情况 | 怎么办 |
| --- | --- |
| 没有全局 univer CLI | 无需额外安装；创建、编辑、检查、导出、预览与 Worktree 审阅均已内置。 |
| 装完看不到卡片 | 确认刷新过（Cmd+R）；卡片只会在该回合使用结构化 `univer_*` 工具后出现。 |
| 卡片上是**黄色圆点** | 内置 Gateway 没运行，点一下圆点即可启动 |
| 想卸载 | 删除 `~/.dsh/profiles/node_modules/dsh-univer-office` 文件夹，并把 `~/.dsh/profiles/web/cordis.patch.yml` 里对应几行删掉 |

## 需要电脑上有什么

- Apple Silicon Mac + 已安装 DeepSeek Harness（当前预构建 zip 的要求）
- 不用会任何命令、不用装 Node —— 双击就行
