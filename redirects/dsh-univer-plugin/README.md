# dsh-univer-plugin (reserved name)

This npm package name is **reserved** by the DSH × Univer plugin project to
prevent typosquatting. It intentionally contains no code.

**The official package is [`dsh-univer-office`](https://github.com/dream-num/dsh-univer-office).**

Install the official plugin with:

```sh
dsh plugin --profile web add github:dream-num/dsh-univer-office
```

or, once published to npm:

```sh
dsh plugin --profile web add dsh-univer-office
```

This placeholder exists only so that `npm install dsh-univer-plugin` can never
be hijacked by a third party impersonating the project. Installing this package
does nothing; use the official name above.
