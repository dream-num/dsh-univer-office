# dsh-univer-office-suite (reserved name)

This npm package name is **reserved** by the DSH x Univer project to prevent
typosquatting. It intentionally contains no code.

**The official package is [`dsh-univer-office`](https://github.com/dream-num/dsh-univer-office).**

Install the official plugin with:

```sh
dsh plugin --profile web add dsh-univer-office
```

This placeholder exists only so that `npm install dsh-univer-office-suite` can never be hijacked
by a third party impersonating the project. Installing this package does
nothing; use the official name above.
